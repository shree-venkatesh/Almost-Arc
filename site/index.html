Zen Browser, almost Arc.

A free mod that gives Zen Arc's look and feel: a centered URL pill, a toolbar tinted to the page, Arc's pop-out sidebar and Picture-in-Picture.

Install

Every way gets the same mod. Each one installs Zen first if you don't have it.

The installer (easiest)

Download the installer, open it and click through. If macOS says it can't verify the developer, open System Settings, then Privacy & Security, and click Open Anyway.

Homebrew

$ brew install shree-venkatesh/tap/almost-arc
$ almost-arc install

No Homebrew? Paste this in Terminal

$ curl -fsSL https://almostarc.net/install.sh | bash

Quit Zen first. Later, almost-arc update updates it and almost-arc uninstall removes it.

With Sine

In Sine, install shree-venkatesh/Almost-Arc. Sine keeps it updated.

Features

What changes in Zen once it's installed.

Centered URL pill

Sized to the address, domain bright and path dimmed. Click it for Zen's floating address bar.

Toolbar tinted to the page

The toolbar takes the color of the top of each page, so it reads as part of the page.

Arc's pop-out sidebar

In compact mode, the sidebar slides out full height with the window buttons at its top.

Auto Picture-in-Picture

A playing video pops out when you switch tabs, apps or desktops, and comes back when you return.

Arc-style PiP controls

Back to Tab, 15-second skips, a slim progress bar. Swipe the window into a corner.

Cmd+Z for tabs

Reopens tabs you closed and puts moved or pinned tabs back, with safeguards.

Updates itself

When a new version is out, Zen shows a bar with an Update button. No Terminal.

Copy link, one click

The copy button sits next to the pill and turns into a checkmark when you copy.

Help

The usual questions.

Zen updated and the mod looks half gone

Zen's updates remove the part of the mod that lives in the app. Zen shows a notice when that happens: run almost-arc install, or open the installer again.

How do I update Almost Arc?

Click Update on the bar Zen shows when a new version is out, or run almost-arc update.

macOS says it can't verify the developer

The installer isn't signed by Apple yet. Open System Settings, then Privacy & Security, and click Open Anyway.

How do I remove it?

Run almost-arc uninstall. Zen goes back to how it was, including its icon.

Does it work on Windows or Linux?

It's built for Zen on macOS. Linux mostly works with ./install.sh; Windows isn't supported.
