Almost Arc

A free mod that makes Zen Browser look and feel almost like Arc.

Install with Homebrew

$ brew install shree-venkatesh/tap/almost-arc
$ almost-arc install

No Homebrew? Paste this in Terminal

$ curl -fsSL https://almostarc.net/install.sh | bash

Quit Zen first. Later, almost-arc update updates it and almost-arc uninstall removes it.

Or with Sine: install shree-venkatesh/Almost-Arc. Needs Zen 1.24 on macOS.
